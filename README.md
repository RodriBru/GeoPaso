# GeoPaso

MVP estático en HTML, CSS y JavaScript puro para resolver paso a paso la figura geométrica del pizarrón.

## Cómo abrirlo

1. Descomprimí la carpeta.
2. Abrí `index.html` con doble clic.
3. No requiere instalar dependencias ni conexión a internet.

También podés usar Live Server en VS Code.

## Qué incluye

- Interfaz responsive basada en el diseño aprobado.
- Foto de referencia y carga de otra imagen.
- Entradas compatibles con coma o punto decimal.
- Resolución paso a paso de la figura ABFED.
- Cálculo de lados auxiliares, ángulos, perímetro y área.
- Comprobación de la suma de los ángulos del pentágono.
- Aviso cuando un dato escrito no coincide con los demás.
- Vista esquemática y vista proporcional.
- Puntos arrastrables para ajustar visualmente el dibujo.
- Impresión de la solución.
- Sin librerías externas.

## Importante

Esta primera versión resuelve la estructura geométrica específica del ejercicio: puntos A, B, C, D, E y F, con C, D y E rectos y las diagonales mostradas. La foto se usa como referencia; todavía no realiza reconocimiento automático de escritura u OCR.
